Cómo instalar y ejecutar SEALSWORN

Desde la versión 0.21.8 puedes elegir entre una instalación guiada para Windows o una versión portable. Recomendamos el instalador para recibir futuras actualizaciones más fácilmente.

Instalador de Windows (.exe) Recomendado

  1. En la última versión, pulsa Descargar instalador (.exe).
  2. Cuando termine la descarga, abre el archivo .exe.
  3. Sigue los pasos del asistente para instalar SEALSWORN. No necesitas permisos de administrador: se instala para tu usuario de Windows.
  4. Abre el juego desde el acceso directo creado por el instalador.
  5. Cuando haya una nueva versión, el juego podrá avisarte y ofrecerte su descarga e instalación.

Versión portable (.zip)

  1. Pulsa Descargar versión portable (.zip).
  2. Extrae todo el contenido del ZIP en una carpeta de tu elección; no ejecutes el juego directamente desde el archivo comprimido.
  3. Abre la carpeta extraída y ejecuta el archivo .exe del juego.

Esta opción permite jugar sin utilizar el asistente de instalación. Conserva juntos los archivos extraídos y consulta las notas de cada versión antes de actualizar manualmente.

¿Windows bloquea el instalador o muestra una advertencia?

Como SEALSWORN es un proyecto independiente en desarrollo, Windows SmartScreen puede mostrar el aviso «Windows protegió su PC» al abrir el instalador o el ejecutable.

  1. Comprueba que has descargado el archivo desde esta web oficial de SEALSWORN, utilizando sus botones de descarga. Los archivos se distribuyen a través de GitHub Releases.
  2. Si Windows muestra una advertencia de SmartScreen y confías en el archivo, pulsa Más información.
  3. Después, si aparece la opción, selecciona Ejecutar de todas formas para continuar.

Importante: no desactives SmartScreen ni el antivirus para instalar el juego. Si el aviso indica que se ha detectado una amenaza o no puedes verificar el origen del archivo, no fuerces la ejecución y consulta la información oficial de esta web.

Instalación de versiones anteriores a la 0.21.8 ⌄

Las versiones anteriores se distribuían como archivos ZIP, sin el nuevo asistente de instalación.

  1. Descarga el ZIP de la versión que quieras probar desde el historial de versiones.
  2. Extrae todo su contenido en una carpeta.
  3. Ejecuta Tower.GameCore.exe (el nombre puede variar según la versión).
  4. Si aparece una advertencia de SmartScreen, comprueba primero que el archivo procede de las Releases oficiales y sigue las indicaciones de seguridad anteriores.

SEALSWORN sigue en desarrollo. Puede haber errores o cambios importantes entre versiones. Si detectas un problema, indica la versión y qué estabas haciendo.

🎒 Mochila, cofres y tienda

  • Arrastrar: mover un objeto; soltarlo fuera de la ventana lo tira al suelo.
  • Clic derecho: usar o equipar.
  • Mayús + clic: pasar un objeto al otro lado (mochila ↔ cofre).
  • Arrastrar un consumible a un hueco Q o R lo asigna.
  • Cofre: T tomar todo (y el oro) · G guardar todo.
  • Tienda: clic para comprar · clic derecho en tu mochila para vender al 40 %. Con Mayús, la pila entera.
  • Con mando, cada pantalla muestra abajo sus botones.

📖 Menús y libro

  • W/S o ↑/↓ (cruceta o stick): mover la selección.
  • Enter / Espacio / clic (A): aceptar.
  • Esc (B): volver atrás o cerrar.
  • Tab / Mayús+Tab (LB / RB con mando): pasar de pestaña en el libro (mochila, habilidades, aliados y mapa).
  • Habilidades: clic en una habilidad para desbloquearla si cumples los requisitos.
